🔥 Conexão Firebase
▾

Cole o objeto firebaseConfig do seu projeto Firebase. Esta configuração é salva no navegador.

1. Acesse console.firebase.google.com → crie um projeto
2. Firestore Database → Criar banco de dados → Modo de produção
3. Regras → cole: allow read, write: if true; → Publicar
4. Configurações do projeto → Seus apps → Adicionar app Web → copie o firebaseConfig
🔐 Senha de administrador
▾

A senha admin permite adicionar e editar tarefas diretamente no calendário. Compartilhe o link com a equipe — só quem souber a senha entra no modo admin.

Depois de salvar, esta senha é exigida toda vez que alguém quiser entrar no modo admin.

🏠 Aba que abre por padrão
▾

Escolha em qual aba o site abre para todos os usuários. A aba geral reúne as tarefas de todas as abas e tem configuração de colunas própria — se você configurou as colunas de uma aba específica, escolha essa aba aqui para que todos a vejam ao entrar.

🎨 Cores por Tag
▾

A primeira tag de uma tarefa determina a cor no calendário. Clique no nome de uma tag para editá-lo — as tarefas existentes são atualizadas automaticamente.

📥 Importar tarefas via Excel
▾

Envie uma planilha (.xlsx, .xls ou .csv) com uma base de tarefas. Depois de carregada, mapeie cada coluna para um campo do calendário — inclusive em qual aba a tarefa deve aparecer. Campos com mais de um valor devem estar separados por ; na célula (ex: Financeiro;Suporte).

Se nenhuma aba for marcada aqui e a coluna "Aba" também estiver vazia, a tarefa aparece só na aba geral.
